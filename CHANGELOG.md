# Changelog

**English** · [简体中文](CHANGELOG.zh-CN.md)

## 1.0.0

Initial public release.

- Display WSL2 folders in Windows desktop boxes and open files with their default Linux applications through WSLg.
- Choose a WSL distribution and folder using a dropdown and folder picker.
- Create multiple independent boxes and save their folders, positions, sizes and display preferences.
- Adjust background transparency, switch between icon and list views, sort and filter files, lock boxes, and collapse or expand them.
- Maximize and restore boxes, snap them to screen edges, and align neighboring boxes.
- Double-click empty Windows desktop space to hide or show boxes; restore boxes below other applications while preserving the foreground window.
- Display Linux file icons, launcher icons and thumbnails.
- Drag and drop, copy, cut and paste files between Windows and WSL, with progress and file-conflict dialogs.
- Rename files in place, create folders, choose a Linux application with Open with, and set default applications.
- Move deleted files to Linux Trash. Permanent deletion requires confirmation; unsupported trash operations preserve files and show an error.
- Use the native Windows file context menu with Linux actions grouped separately.
- Navigate with mouse back/forward buttons or keyboard shortcuts, and return to the configured folder after browsing subfolders.
- Copy Linux paths and find file, navigation and window shortcuts in grouped help tables.
- Choose English, Simplified Chinese or the system language as a global preference.
- Support configured Fcitx, Fcitx5 and IBus input methods while keeping applications usable when no input method is available.
- Open Linux applications independently of remote-desktop session settings, without requiring a full Linux desktop.
- Provide a project link, manual update checking and optional environment diagnostics.
- Improve responsiveness when opening files and loading folders, icons and thumbnails, and keep saved layouts stable when closing boxes.
